# IoT Command Center

A centralized platform for monitoring, managing, analyzing, and controlling IoT devices and sensor networks in real time.

## Current hosted build

- React + TypeScript + Vite
- Tailwind-compatible styling system
- Persistent device/sensor/reading/alert/event data
- Managed authentication
- REST-style API routes
- WebSocket realtime updates
- Ten realistic simulated devices
- Gradual telemetry simulation with threshold alerts
- Device command workflow
- Analytics, map, event stream, alert center, settings and responsive UI

## Run

Open the deployed application URL and use the navigation. The initial data set is seeded automatically.

## Local-production extension

The full original portfolio brief also targets FastAPI, PostgreSQL, Redis, Mosquitto MQTT, Docker Compose, Nginx, Prometheus and Grafana. Those services require a conventional Linux/Docker runtime and are documented as the next local deployment layer. See docs/architecture.md.

## Portfolio highlights

This project demonstrates distributed-system concepts, realtime state propagation, IoT device modeling, telemetry processing, threshold-based alerting, role-aware application structure, persistent data, and an operations-focused dashboard.


## Repository

This repository contains the deployed AppDeploy source snapshot, including the installable PWA shell.

## Install on Windows

Open the hosted application in Chrome or Edge and use the browser's install-app option to install IoT Command Center as a desktop-style application.
